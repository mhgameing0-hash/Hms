=======================================================
HMS (Home Maintenance System) - Android Release Package
=======================================================

Included in this bundle:
1. app-release.apk (19.8 KB)
   - Standalone Android APK file for direct installation on any Android phone.
   - Simply copy this file to your phone, tap it, and click 'Install'.
   - If prompted, allow 'Install from unknown sources' in settings.

2. app-release.aab
   - Android App Bundle for Google Play Console publishing.
   - Target SDK: 34 (Android 14 Ready).

3. hms-flutter-project.zip
   - Complete Flutter 3.19+ source code.
   - Includes lib/main.dart, pubspec.yaml, and android/ configuration.

4. main.dart
   - Complete single-file Flutter source code containing all 13 civil & home maintenance services,
     3D water buttons, worker wallet, and cost calculator.

5. Android Configuration:
   - pubspec.yaml
   - AndroidManifest.xml
   - build.gradle
   - key.properties

=======================================================
How to Upload to Google Drive manually:
=======================================================
1. Go to https://drive.google.com
2. Click '+ New' -> 'File upload'
3. Select 'app-release.apk' from this folder
4. Right-click the uploaded file in Drive -> 'Share' -> change to 'Anyone with the link'
5. Copy the link and send it via WhatsApp or email to anyone!
